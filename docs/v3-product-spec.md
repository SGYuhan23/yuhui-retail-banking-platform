# 渝惠｜银行零售客户经营与场景权益平台 · V3 P0 产品说明

## 目标与范围
围绕“客户—商户—场景—预算—权益”，实现可治理、可执行、可追溯的经营闭环。渝研负责研究，本项目负责运营；不添加 Agent、推荐模型、支付、清结算或收入预测。

用户角色为本地演示中的运营人员、模拟商户和合成消费者；没有真实多人授权。主路径：客群规则 → 不可变快照 → 经营方案 → 复核 → 不可变版本 → 投放批次 → 领取 → 预算预占 → 核销 → 实扣 → 复盘 → 人工决策。

## P0 产品规则
- 客户固定 SYN 编号，不存姓名、手机或证件。A1–A4 仅 Demo Tier。NEW/ACTIVE/AT_RISK/DORMANT 分别显示新客/活跃/待唤醒/沉默。
- 白名单字段进行 AND/OR 筛选，预览展示总匹配及同意营销的人数、生命周期/资产层级分布。快照强制排除未同意营销者，后续属性变化不改历史成员；触达/参与/领取时再次检查当前许可。
- 三种经营目标：客户唤醒、商户引流、积分消耗。仅后者要求积分价格大于零。目标行为限定模拟社区消费或模拟有效活跃。
- DRAFT → PENDING_REVIEW → APPROVED → PUBLISHED → RUNNING → ENDED；待复核可退回草稿。发布后禁止编辑；新方案另建草稿。
- 发布时冻结规则对应客群、场景、商户集合、权益全部条款、成本、银行预算、KPI、停止规则及窗口。创建批次写入 ELIGIBLE。
- P0 一个活动默认一个批次，分配额为预算和硬上限较小者；服务端在 campaign 父行事务锁内检查所有批次累计分配不超过 min(活动总预算, 已配置硬上限)，硬上限为空则使用总预算。未实现可视化多批次预算拆分。
- 每个客户每批次每权益限领一次（取消/过期也不恢复领取次数）；领取绑定一家冻结范围内商户，库存累计已发口径；过期/取消不回补已发库存。
- 领取同时执行库存条件更新、积分扣减（如适用）、权益生成、预算预占、事件写入，任一步失败整体回滚。积分兑换取消退回合成积分并记 POINTS_REFUNDED；过期不退积分。
- 核销检查码、状态、领取时间、有效期、商户、场景与最低模拟消费金额。核销仅一次成功；预占转实扣。批次结束不提前作废仍有效权益。
- 到期释放每 60 秒执行一次；总览允许手动执行。取消只允许权益对应演示客户。有效期到达即拒绝核销，最迟下一轮任务释放预算。
- 金额内部统一整数分；复盘按元显示。预占与实扣之和不超过预算；已释放是累计流水口径。
- 触达与目标行为均为显式模拟操作，没有实际短信/推送/消费通道。目标行为必须在本案例核销后独立记录且符合预定义类型，不由核销自动推定。

## 指标与经营判断
复盘展示冻结人数、有效触达、参与、领取、核销、目标行为客户数。事件计数按客户去重；预算和成本从流水聚合，分母为零显示空值。核销率、预算占用率、单位目标行为成本提供确定性预警。商户核销率低于 20% 提示可考虑减少下一轮额度。运营人员在结束批次后手工记录 EXPAND / KEEP / REDUCE / STOP，原因与当时指标快照永久保存。

禁止将目标行为解释成因果唤醒；不提供 ROI、收入/GMV/LTV 增长、虚构 A/B、NPS。

## 前台与旧能力
保留重庆主视觉、签到、积分、抽奖、原钱包；新增生活权益领取区及场景权益钱包，展示有效期/商户/门槛/状态。消费者响应移除银行成本与商户让利。SYN 客户积分属于可重置合成数据；原固定账户 10002 的积分/抽奖不受重置影响，UI 明确区分，不伪装成同一银行账户。

## 验收
详见 verification/final-patch/ 与 verification/public-release/。新页面并非静态原型；领取、核销、预算、事件、决策均持久化 MySQL。

## FINAL PATCH：复核与时间语义

提交复核将执行字段（含 Segment 规则、权益成本、商户范围、目标与窗口）稳定序列化并 SHA-256，排除更新时间、已发库存及 UI 字段。页面可查看提交快照。批准不会刷新该内容。发布在事务锁内比较当前执行配置；变更则拒绝并持久化 DRAFT 状态。重新提交、批准后发布。版本保存批准配置及 hash。

手工 Snapshot 是留存观察；Campaign 发布时按复核一致的规则创建发布 Snapshot，Run 使用该快照。客户属性仍可能在提交与发布之间变化，不声称复核时已冻结客户成员。

目标值取发布版本；实际为 `[run.start_time, run.end_time]` 内 TARGET_ACTION_COMPLETED 去重客户数；差额=实际−目标，完成率=实际/目标，实际≥目标即达标。Run 窗口用于投放/领取和目标观察，结束不提前终止有效权益。核销/成本/预算为截至复盘时间累计履约。AVAILABLE（包括待定时释放）计未履约；全部 REDEEMED/EXPIRED/CANCELLED 才为 SETTLED。投放结束但待履约时提示 ONGOING，仍允许保存阶段决策及当时完整指标。
