# 事实边界

渝惠为个人银行零售经营产品实践，非任何银行官方/内部系统。

没有真实银行客户数据、真实银行账户、真实商户、真实支付或清结算；没有任何银行内部数据和系统接入；不主张真实营销uplift、ROI、客户增长或生产容量。

验证范围为产品流程、业务规则、预算约束、状态一致性、事件追溯、Synthetic场景复现、并发与幂等。合成案例224名目标行为客户、149.3%完成率不是实际经营业绩。

本地固定身份、公开演示密码、回环绑定只适合隔离的本机Demo；不能部署为公网服务。当前凭据值 yuhui_local_only/local/change-me/guest 等是演示配置或占位符，不是可公开复用的生产凭据。

冻结细节、已知P2及非活跃中间件边界见 [V3事实说明](v3-truth-boundaries.md)。随包测试结果为本地工程证据，远端 CI 状态见仓库 Actions。
